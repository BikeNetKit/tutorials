# Tutorial 1 
**Introduction to GrowBikeNet** · *15 Minutes*  

<small>Presented the first time at [D3A](https://d3aconference.dk/data-science-of-human-centric-mobility/), Nyborg, Oct 8th 2026.  

Using GrowBikeNet v0.14.5  
Created 2026-09-30 by Michael Szell: contact@bikenetkit.org</small>

## Prerequisities

- You have [conda](https://docs.conda.io/projects/conda/en/latest/index.html) installed (or the faster [mamba](https://mamba.readthedocs.io/en/latest/index.html)).
- You have a UNIX/Mac-based terminal.

## Setup

First, download and unzip the `tutorial01` folder: 

👉 [**https://tinyurl.com/d3abikenetkit**](https://downgit.github.io/#/home?url=https://github.com/BikeNetKit/tutorials/tree/main/python/tutorial01) 👈


Then use the terminal to navigate to this folder. 

Install python, growbikenet, and fixbikenet via:  
```
conda env create --file environment.yml
``` 

Then, activate the environment via:  
```
conda activate bikenetkit_tutorials 
```

and run jupyter lab:  
```
jupyter lab tutorial01.ipynb
```

Now, a browser window with the tutorial should open.
